GS1-01 · 12 min

Typography & spacing for worship screens

Like the rest of your church's slide toolkit, Google Slides lives in the cloud — decks sync instantly across the booth, the pastor's office, and home, so edits made anywhere show up everywhere. But sync doesn't fix a hard-to-read slide. Readability on a sanctuary screen still comes down to three settings: line spacing, paragraph spacing, and indentation.

SettingWhat it controls
Line spacingVertical space between lines within the same verse or paragraph
Paragraph spacing (before/after)Vertical space between distinct stanzas, verses, or bullet points
Hanging indent (ruler)Alignment between a bullet symbol and the wrapped text beneath it
Skip the blank-line workaround: use Format → Line & paragraph spacing → Add space after paragraph instead of empty line breaks — blank lines create gaps that shift unpredictably across different screen resolutions.
  • Set line spacing to 1.15–1.5 on lyric and scripture body text
  • Use Tab to demote a sermon point to a sub-bullet, Shift+Tab to promote it back
  • Show the ruler (View → Show ruler) before adjusting any hanging indent
  • Drag the top triangle marker to set where the bullet symbol starts, the bottom marker to set where wrapped text aligns
GS1-02 · 15 min

Building your church template with Theme Builder

Theme Builder (View → Theme Builder) is a two-tier system: a top-level Theme slide controls global branding — logo, background, fonts — while Layout Slides beneath it define specific content types like lyric slides, scripture slides, and lower-thirds. In a volunteer-run booth, it doubles as protection: anything anchored inside Theme Builder is locked into the slide background, safe from being accidentally dragged during a live text edit.

  • Anchor logos and background graphics inside the Theme or Layout — never as a loose canvas element
  • Type new slide content into a layout placeholder, not a hand-drawn text box

Correct — layout placeholders are locked into position by the template; text boxes are free-floating.
GS1-03 · 10 min

Formatting lyric & scripture slides

Lyric and scripture slides are the most-seen content in any service, and both should be built from the layout placeholders you set up in the last lesson — never a fresh text box.

  • Build a dedicated Lyric layout with centered, high-contrast body text inherited from your Theme
  • Build a dedicated Scripture layout with the citation (book, chapter, verse) placed in the same spot every time
  • Type directly into the layout placeholder so paragraph spacing and font styling apply automatically
  • Apply the paragraph-spacing rule from Lesson 1 between verses instead of blank lines
Because media embeds directly into the canvas, worship background videos, testimony clips, and baptism footage can live inside the same lyric layout without leaving Slides — insert them once, not slide-by-slide each Sunday.
GS1-04 · 12 min

Presenter View & sanctuary display setup

Presenter View splits your screen into a private control console — speaker notes, a preview of the upcoming slide, a live timer, and a slide-jump dropdown — while the audience display shows only the full-screen presentation.

▶
How to View Speaker Notes While Presenting in Google Slides Watch on YouTube ↗
  • Click the dropdown next to Present and choose Presenter view
  • Confirm the booth laptop is set to Extended display, not Mirrored
  • Route the audience-facing window to the sanctuary projector or LED in full-screen mode
  • Use the slide-jump dropdown to skip directly to a slide number instead of clicking through every slide
Mirrored-display leak: Presenter View only works cleanly on an extended display. On a mirrored display, your private speaker notes get projected straight to the congregation.

GS1-06 · 10 min

Audience Tools — live Q&A

Audience Tools opens a web URL banner at the top of the main screen so attendees can submit questions from their own devices — useful for Sunday school classes, elder Q&A nights, or any interactive teaching session.

▶
Make Slides Interactive: Audience Q&A & Blank/White Screen Tricks Watch on YouTube ↗
  • Press A, or click Audience tools in Presenter view, to open the Q&A dashboard
  • Share the on-screen URL banner so attendees can submit questions from their phones
  • Use the upvote count to choose which questions to display on the main screen
  • Reserve this for interactive formats — Sunday school, testimony nights — not a standard main-service sermon
